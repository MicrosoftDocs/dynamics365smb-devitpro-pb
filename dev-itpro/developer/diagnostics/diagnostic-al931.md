# Compiler Error AL0931

[!INCLUDE[banner_preview](../includes/banner_preview.md)]

'{0}' is not a namespace or a valid {1} reference.


## Description
The right side of the '::' operator must be a namespace or the name of an application object of the expected kind, such as 'Codeunit::MyCodeunit'. It cannot be further qualified with a member access.
