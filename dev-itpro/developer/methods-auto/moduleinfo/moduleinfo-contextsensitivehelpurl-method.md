# ModuleInfo.ContextSensitiveHelpUrl() Method
> **Version**: _Available or changed with runtime version 18.0._

Gets the context sensitive help URL with the user's locale resolved from the application's supported locales.


## Syntax
```AL
ContextSensitiveHelpUrl :=   ModuleInfo.ContextSensitiveHelpUrl()
```
> [!NOTE]
> This method can be invoked using property access syntax.
## Parameters
*ModuleInfo*  
&emsp;Type: [ModuleInfo](moduleinfo-data-type.md)  
An instance of the [ModuleInfo](moduleinfo-data-type.md) data type.  

## Return Value
*ContextSensitiveHelpUrl*  
&emsp;Type: [Text](../text/text-data-type.md)  
The context sensitive help URL with the user's locale resolved.
