# ModuleInfo.PrivacyStatement() Method
> **Version**: _Available or changed with runtime version 18.0._

Gets the privacy statement link of the specified application.


## Syntax
```AL
PrivacyStatement :=   ModuleInfo.PrivacyStatement()
```
> [!NOTE]
> This method can be invoked using property access syntax.
## Parameters
*ModuleInfo*  
&emsp;Type: [ModuleInfo](moduleinfo-data-type.md)  
An instance of the [ModuleInfo](moduleinfo-data-type.md) data type.  

## Return Value
*PrivacyStatement*  
&emsp;Type: [Text](../text/text-data-type.md)  
The privacy statement link of the specified application.
