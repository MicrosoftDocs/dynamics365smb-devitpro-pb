# FAQ about managing and submitting your Business Central offer

Find answers about managing your [!INCLUDE[prod_short](../includes/prod_short.md)] offer in Partner Center, submitting changes, and completing Marketplace publication.

## If I select the Go Live button, does that mean my app goes live to Marketplace?

Yes. At **Publisher signoff**, select **Go Live** to approve publication of the preview version to Marketplace. The offer becomes live after the remaining publishing steps finish. To start a submission for validation, use **Review and publish**, then select **Publish**.

Learn more about [publishing a preview version](devenv-checklist-submission-app-preview.md#how-do-i-go-live-with-my-preview-version).

## What should I know about the review and publish button?

Select **Review and publish** when you're ready to submit changes. Review the section statuses, resolve incomplete sections, and make sure the changed content that you intend to submit is included. Ensure all checkboxes are marked on that page. Then select **Publish** to start validation and publishing.

Learn more about [reviewing and publishing an offer](/partner-center/marketplace-offers/review-publish-offer) and [updating an existing offer](/partner-center/marketplace-offers/update-existing-offer).

## I only made marketing changes. Will my app have to go through technical validation?

Technical validation is skipped for unchanged app packages whose same versions are already validated and uploaded for the applicable target countries/regions. An unchanged package can still require validation where that previous validation doesn't apply, such as when adding a new target country or region. Don't assume that a marketing-only submission skips every technical-validation task.

Learn more about [which apps are validated in a submission](devenv-checklist-submission-validation-process.md#which-apps-are-validated-in-my-submission).
