# AppSourceCop Error AS0150
Fully-namespaced app objects must be in a compliant namespace

## Description
When the FullNamespaceScope feature is enabled, all objects must be declared in a compliant namespace with at least two levels (e.g., 'Publisher.Module'). Objects without a compliant namespace cannot rely on affixes for name collision avoidance.
