# APIGroup property on API queries

> **Version**: _Available from runtime version 1.0._

<!-- this article is manually created, and the parent node is devenv-apigroup-property.md -->

Specifies the group segment of the API endpoint that exposes the query. The following example defines the group as `app1`.

## Applies to

- Query object

## Syntax

```al
APIGroup = 'app1';
```

For a complete example, see [API query type](../devenv-api-querytype.md).
