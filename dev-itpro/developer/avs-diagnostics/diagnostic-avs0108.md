# AVS Error AVS0108

The following extension(s) could not be found. Upload the missing extensions and try again. {0}.

## How to fix this diagnostic?

Upload the missing dependent extensions with the submission, and then try again. For per-tenant extension validation, also confirm that required dependencies are installed and that their publisher, name, and version are compatible.
