## Upgrade to 29.0

### Online customers

- New customers automatically get Business Central version 29.0.
- Existing customers get a notification when update 29.0 is available. Admins can schedule update 29.0 to any date within the five-month update period, which ends in February 2027.

Learn more in [Major updates for Business Central online](../administration/update-rollout-timeline.md#major-updates).

### On-premises customers

Deployments using version 24 or earlier must upgrade to version 25 before upgrading to version 29. Learn more in [Upgrading to Dynamics 365 Business Central 2026 release wave 2](../upgrade/upgrade-overview-v29.md).

The base application no longer includes several objects that were marked as obsolete in these earlier versions. Learn more in [Important information and considerations when upgrading to Business Central version 29](../upgrade/upgrade-considerations-v26.md).
