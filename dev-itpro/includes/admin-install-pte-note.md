> [!IMPORTANT]
> The recommended way to upload, install, and manage per-tenant extensions is now the [Business Central Admin Center](../administration/tenant-admin-center-manage-apps.md) and its [API](../administration/administration-center-api_app_management.md). The in-product **Extension Management** upload flow and the Automation API `extensionUpload` endpoint are deprecated and planned for removal in 2027 release wave 1. Learn more in [Deprecated features in the platform](../upgrade/deprecated-features-platform.md).
